# Atlas IoT IDE (Lab 5)

Visual Integrated Development Environment for the Atlas 3.0 IoT Platform.

## Quick Start

1. Start the IDE server:
   ```bash
   python run_ide.py
   ```

2. Open your browser at:
   ```
   http://localhost:5050
   ```

## Tabs Overview

- **Things**: Discovers and displays connected Raspberry Pi devices and their hardware info.
- **Services**: Lists all offered microservices, categorized into Sensors and Actuators.
- **Relationships**: Interactive visual graph showing Order-based and Condition-based links.
- **Apps & Editor**: Compose apps (Type 1, 2, 3), save them as `.iot` files, and run them.
- **Status Panel**: Bottom panel showing running apps, live values, and Stop controls.
